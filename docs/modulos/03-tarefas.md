# Tarefas

## O que é hoje
Quadro **com colunas editáveis** (criar/renomear/remover), prioridade, tags, prazo no fuso efetivo, vínculo opcional com cliente e agenda, comentários + notificação.  
Tarefas atrasadas geram alerta (`todo_overdue`) e aparecem destacadas no quadro / Modo operação.

## Regras conhecidas
- Task **geral** = visível para a equipe; pessoal = responsável.
- Mover para coluna “conclui” marca Done.
- **Agenda ≠ tarefa** — ciclo de vida distinto; vínculo opcional (reunião pode *nascer* tarefas via decisão).
- Tarefa concluída + SOP run + decisão = evidência dos relatórios (cliente / ADM / VA).
- Evolução prevista: Demanda → várias tarefas + grupo de acesso (ver BRIEFING-ALINHAMENTO-JU).

## Perguntas essenciais
1. Task pessoal vs geral: quem vê o quê?
2. Precisa de subtarefas / checklist dentro da task?
3. Quando uma task atrasa, além do alerta: escalar? WhatsApp?
